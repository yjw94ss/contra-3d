# 钢铁突袭 · 3D 魂斗罗

一个用 Three.js 写的 3D 横版卷轴射击游戏 —— 魂斗罗的经典玩法，架在真正的三维战场上。

## 为什么是 3D

不是把 2D 画面套个 3D 皮。战场有**第三个轴（Z 纵深）**：

- 玩家在 X（推进）× Z（纵深）平面上机动，敌人分布在不同纵深层
- 镜头带透视和视差，远景山丘、星空随推进滚动
- 掩体挡子弹的角度、敌人包围的站位，全都因为纵深而改变

保留了魂斗罗的手感内核：8 向射击、边跑边打、跳跃越过矮掩体、卧倒躲弹、一次死亡损失一条命。

## 操作

### 键盘 / 鼠标（桌面端）

| 键位 | 功能 |
|---|---|
| `A` / `D` 或 `←` `→` | 左右推进 |
| `W` / `S` 或 `↑` `↓` | 纵深移动（进出不同纵深层） |
| 鼠标 | 瞄准 |
| 左键 / `J` | 射击（可边跑边打） |
| `空格` / `K` | 跳跃 |
| `Shift` / `L` | 卧倒（低姿射击，可躲弹） |
| `P` / `Esc` | 暂停 |
| `M` | 静音 |

### 触屏（手机横屏）

| 操作 | 功能 |
|---|---|
| 左半屏拖动 | 虚拟摇杆移动（X 推进 + Z 纵深） |
| 右半屏按住 | 朝触点方向持续射击 |
| 跳跃键 | 跳过矮掩体 |
| 卧倒键 | **切换式**低姿，躲避正面弹道 |

手机端自动启用触控层，桌面端不显示任何触控 UI。竖屏会提示旋转设备。

## 武器

| 代号 | 武器 | 特点 |
|---|---|---|
| M | 机枪 | 初始武器，攻守均衡 |
| S | 散弹 | 5 发扇形，近距离爆发高 |
| F | 火焰喷射器 | 高射速，弹道带火焰拖尾 |

| L | 激光枪 | 高伤害，**穿透** 2 个目标 |

击杀敌人有概率掉落医疗包和武器。

## 关卡：六个区域，六种 BOSS

一局要打完六个区域，每关有独立的主题配色、地形长度、敌人配比和 BOSS。
关卡之间有开场过场动画与结算面板（过关得分 / 击破 / 用时 / 命中率 / 剩余生命 / 累计总分）。

| 关 | 区域 | 主题 | BOSS | 特点 |
|---|---|---|---|---|
| 1 | 前沿哨站 | 夜间 | 铁壁 · 重装机甲 | 三连扇形弹 + 环形弹幕 + 火箭 |
| 2 | 工业走廊 | 工业 | 重炮堡垒 | 双管齐射 + 高抛散射弹 |
| 3 | 荒漠隘口 | 沙尘 | 蜂巢母舰 | 悬停，召唤蜂群盘旋射击 |
| 4 | 冻土要塞 | 风雪 | 鹰眼 · 狙击要塞 | 高速精准狙击弹 + 旋转护盾片 |
| 5 | 熔岩核心 | 熔岩 | 炽炎 · 战争堡垒 | 熔岩环脉动 + 环形弹幕 + 侧翼火箭 |
| 6 | 天穹要塞 | 紫电 | 终焉 · 指挥官 | 巨型人形机甲，追踪弹 + 终局弹幕 |

每个 BOSS 都是三阶段（默认在血量 68% / 34% 处切换，个别 BOSS 另有阈值），
阶段切换时会有爆炸和警报。弱点是**发光核心**：三阶段时核心周期性暴露，命中造成 2.5 倍伤害。

主题切换会同时改变天空/雾色、灯光色温、地形配色、远景山丘，以及环境粒子
（雪 / 火星 / 沙尘）和主题专属装饰物（工业支架、管道等）。

## 敌人

- **步兵** — 推进到射程后侧移射击，会躲掩体
- **冲锋兵** — 高速直冲，威胁近身
- **狙击手** — 保持 20 米距离，高伤精准弹
- **炮台** — 固定火力点，炮管跟踪玩家
- **无人机** — 悬停绕圈，从空中俯冲射击
- **重装兵** — 高血高伤，三连发弹雨

每关的敌人配比不同，且后 35% 路程会切换成强化配比（加入狙击手、重装兵等）。

## 运行

```bash
cd contra3d
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

需要 WebGL 支持的现代浏览器。Three.js 已放在 `vendor/`，**无需联网**。

## 技术要点

- 纯 JavaScript + Three.js（r160），无构建步骤
- 所有模型用基础几何体程序化拼装，零外部资源
- 音效与 BGM 由 WebAudio 实时合成，零音频文件
- **关卡配置驱动**：`stages.js` 一张表写完六关的主题、长度、敌人权重与 BOSS 类型，引擎不写死任何一关
- **BOSS 基类 + 子类策略**：`boss.js` 管通用三阶段状态机、血量、判定与攻击工具，各关 BOSS 只覆写建模与攻击行为
- **BOSS 战自适应镜头取景**：按玩家与 BOSS 的中点和间距反推所需后拉距离并夹紧，保证双方始终同框
- **每个 BOSS 独立命中判定盒**：判定盒中心高度与半高按各自模型几何单独标定，子弹沿枪口高度水平飞行也不会从高个 BOSS 腿下穿过去
- **连续碰撞检测**：子弹高速移动时在上一帧→当前位置的线段上采样（6 个采样点），避免穿透目标
- **8 向吸附在屏幕坐标系下计算**：先转屏幕空间再吸附，斜俯视镜头下射击方向才不会歪
- 瞄准辅助：准星接近 BOSS 时锁定精确方向（大型目标需要精确瞄准）

## 目录

```
contra3d/
├── index.html
├── style.css
├── vendor/three.module.js
└── src/
    ├── main.js       主循环 / 场景 / 镜头 / HUD / 状态机 / 关卡流转
    ├── stages.js     六关配置表（主题 / 长度 / 敌人配比 / BOSS 类型）
    ├── player.js     玩家：移动、跳跃、卧倒、8向射击
    ├── enemies.js    六种敌人 AI
    ├── boss.js       BOSS 基类：三阶段状态机 / 判定盒 / 攻击工具
    ├── bossModels.js 六种 BOSS 外观模型（程序化拼装）
    ├── bullets.js    子弹池 + 连续碰撞检测
    ├── effects.js    粒子、爆炸、枪口火光、镜头抖动
    ├── pickups.js    道具拾取
    ├── level.js      关卡地形与刷怪节奏
    ├── models.js     程序化建模
    ├── input.js      键鼠输入
    ├── touch.js      移动端触控层（摇杆 / 瞄准 / 功能键）
    ├── audio.js      WebAudio 音效合成
    └── util.js       数学工具
```
