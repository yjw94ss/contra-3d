# 钢铁突袭 · 3D 魂斗罗

一个用 Three.js 写的 3D 横版卷轴射击游戏 —— 魂斗罗的经典玩法，架在真正的三维战场上。

## 为什么是 3D

不是把 2D 画面套个 3D 皮。战场有**第三个轴（Z 纵深）**：

- 玩家在 X（推进）× Z（纵深）平面上机动，敌人分布在不同纵深层
- 镜头带透视和视差，远景山丘、星空随推进滚动
- 掩体挡子弹的角度、敌人包围的站位，全都因为纵深而改变

保留了魂斗罗的手感内核：8 向射击、边跑边打、跳跃越过矮掩体、卧倒躲弹、一次死亡损失一条命。

## 操作

### 键盘 / 鼠标（桌面端）

| 键位 | 功能 |
|---|---|
| `A` / `D` 或 `←` `→` | 左右推进 |
| `W` / `S` 或 `↑` `↓` | 纵深移动（进出不同纵深层） |
| 鼠标 | 瞄准 |
| 左键 / `J` | 射击（可边跑边打） |
| `空格` / `K` | 跳跃 |
| `Shift` / `L` | 卧倒（低姿射击，可躲弹） |
| `P` / `Esc` | 暂停 |
| `M` | 静音 |

### 触屏（手机横屏）

| 操作 | 功能 |
|---|---|
| 左半屏拖动 | 虚拟摇杆移动（X 推进 + Z 纵深） |
| 右半屏按住 | 朝触点方向持续射击 |
| 跳跃键 | 跳过矮掩体 |
| 卧倒键 | **切换式**低姿，躲避正面弹道 |

手机端自动启用触控层，桌面端不显示任何触控 UI。竖屏会提示旋转设备。

## 武器

| 代号 | 武器 | 特点 |
|---|---|---|
| M | 机枪 | 初始武器，攻守均衡 |
| S | 散弹 | 5 发扇形，近距离爆发高 |
| F | 火焰喷射器 | 高射速，弹道带火焰拖尾 |
| R | 速射枪 | 极高射速，弹速快 |
| L | 激光枪 | 高伤害，**穿透** 2 个目标 |

击杀敌人有概率掉落医疗包和武器。

## 敌人

- **步兵** — 推进到射程后侧移射击，会躲掩体
- **冲锋兵** — 高速直冲，威胁近身
- **狙击手** — 保持 20 米距离，高伤精准弹
- **炮台** — 固定火力点，炮管跟踪玩家
- **无人机** — 悬停绕圈，从空中俯冲射击
- **重装兵** — 高血高伤，三连发弹雨

## BOSS：铁壁 · 重装机甲

三阶段战斗：

1. **一阶段** — 三连扇形弹 + 持续扫射
2. **二阶段**（66% 血）— 环形弹幕，全向覆盖
3. **三阶段**（34% 血）— 火箭轰击 + 核心暴露

弱点：**橙色核心**。三阶段时核心会周期性暴露，命中造成 2.5 倍伤害。

BOSS 还会召唤悬浮炮台支援。

## 运行

```bash
cd contra3d
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

需要 WebGL 支持的现代浏览器。Three.js 已放在 `vendor/`，**无需联网**。

## 技术要点

- 纯 JavaScript + Three.js（r160），无构建步骤
- 所有模型用基础几何体程序化拼装，零外部资源
- 音效与 BGM 由 WebAudio 实时合成，零音频文件
- **连续碰撞检测**：子弹高速移动时在上一帧→当前位置的线段上采样，避免穿透目标
- **8 向吸附在屏幕坐标系下计算**：先转屏幕空间再吸附，斜俯视镜头下射击方向才不会歪
- 瞄准辅助：准星接近 BOSS 时锁定精确方向（大型目标需要精确瞄准）
